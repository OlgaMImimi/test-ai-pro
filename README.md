# Прототип системы инвестпланирования

Одностраничный прототип по требованиям из раздела **«2. Макропараметры»**:

- дерево разделов (создание, переименование, удаление пользовательских разделов);
- CRUD записей в любом разделе;
- подтверждение удаления;
- обязательные поля и валидация;
- раздел **«Глобальные параметры»** с колонками: Название, Версия, Автор, Дата изменения;
- проверка уникальности пары **Название + Версия**;
- выбор экономической модели;
- выбор источников цен из раздела «Цены»;
- редактирование прочих параметров с выбором из «Глобальные данные».

## Запуск

Откройте `index.html` в браузере.
